# Provenance

The agent implementations and synthetic tool-retry scenario originate in this
repository. The governance documents, contribution templates, license, source
header checker and workflow pin check derive from packdb-oss/packdb-sdk at
`87f6c5f64f3170c71bb7e6464adcbd0c9fb3cf74` under Apache-2.0.
The header checker also recognizes TypeScript source and pip dependency inputs.

The examples install upstream dependencies from PyPI and npm. Review both
lockfiles when changing dependencies. No third-party runtime is vendored.

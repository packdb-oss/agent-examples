# Source notices

Begin each Python and TypeScript file with the following two lines in the
language's comment syntax. Preserve existing years when editing a file.

    Copyright 2026 PackDB Contributors
    Licensed under the Apache License, Version 2.0

A shebang may precede the notice. The checker classifies every tracked file,
including tests and tooling. Run `python scripts/check_source_headers.py`
after staging new files. Exceptions require a tracked path, provenance and
reason in `scripts/source_header_exceptions.txt`.
